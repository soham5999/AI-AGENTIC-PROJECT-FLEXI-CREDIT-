# VehicleCare AI: REST API Documentation & Curl Examples

Interactive OpenAPI / Swagger documentation is automatically generated by FastAPI and available at:
- **Swagger UI:** `http://localhost:8000/docs`
- **ReDoc:** `http://localhost:8000/redoc`

All endpoints are prefixed with `/api`.

---

## 1. System Health
### `GET /api/health`
Returns system status, active database connection, and AI agent mode.

```bash
curl -X GET "http://localhost:8000/api/health"
```

**Response (200 OK):**
```json
{
  "status": "online",
  "service": "VehicleCare AI",
  "version": "2.4.0",
  "database": "connected",
  "ml_engine": "online",
  "agent_status": "ready"
}
```

## 2. Machine Learning Prediction
### `POST /api/predict`
Runs the Scikit-Learn Random Forest Classifier on telemetry data.

```bash
curl -X POST "http://localhost:8000/api/predict" \
     -H "Content-Type: application/json" \
     -d '{
       "vehicle_age": 3,
       "odometer_km": 62450,
       "days_since_service": 195,
       "battery_voltage": 11.9,
       "engine_temp": 99.0,
       "brake_wear_pct": 78.0,
       "tire_pressure_avg": 30.0,
       "oil_life_pct": 22.0,
       "vehicle_id": "v-camry-01"
     }'
```

**Response (200 OK):**
```json
{
  "id": "pred-1718000000000",
  "timestamp": "2026-03-21 10:30:00",
  "probability": 85.0,
  "riskLevel": "HIGH",
  "maintenanceRequired": "YES",
  "affectedAreas": [
    {
      "name": "Brake System",
      "severity": "Critical",
      "detail": "Brake pad friction material worn down to 78% (Safety limit: 65%)"
    },
    {
      "name": "Engine Lubrication",
      "severity": "Moderate",
      "detail": "Engine oil viscosity degraded, only 22% remaining life"
    }
  ],
  "model_version": "RandomForest-v2.4"
}
```

## 3. Agentic AI Diagnostic
### `POST /api/agent/analyze`
Executes the multi-tool diagnostic pipeline with Groq Llama-3.3 or local fallback synthesis.

```bash
curl -X POST "http://localhost:8000/api/agent/analyze" \
     -H "Content-Type: application/json" \
     -d '{
       "query": "Perform complete maintenance diagnostic for my vehicle and give action items.",
       "vehicle_id": "v-camry-01"
     }'
```

**Response (200 OK):**
